# 0.4.8 — comparison and conversion feedback

Compare preview opens a split modal with a sandboxed original website and editable output. Both live frames use the same device width and zoom; Fit both panes adapts to the panel width. Original sites may block framing; Open original and the clearly labelled desktop snapshot remain available. Source refresh is separate from rebuilding the draft.

Build requests from the UI stream actual server stage messages, followed by one complete result or explicit failure. No invented percentage, partial unvalidated template, or automatic paid retry. Closing the conversion dialog does not cancel the build. Completed output opens for comparison. Text and design edits retain the existing live preview and save pipeline.

80 unit tests pass, including chunked stream parsing, server failure and truncated-response checks. TypeScript passed. This release does not fix the previously observed BLS page-complexity failure or claim 100% visual similarity. Public-site capture and WordPress visual acceptance still require verification.
